### 1. Objective

The primary objective of this project was to develop a machine learning model capable of predicting the estimated "Story Points" for Jira issues based on the free-text content of their "Detailed Description". The goal is to potentially assist with or automate the initial story point estimation process.

### 2. Data

The analysis utilized a very small dataset loaded from `issues.csv`, containing a total of **200 Jira issues** and **5 columns**.

The key columns used for the predictive model were:
* **'Detailed Description'**: Used as the input feature (X), containing the text describing the issue.
* **'Story Points'**: Used as the target variable (y), representing the numerical story point estimate.

During initial data preparation, checks for missing values and non-numeric entries in the 'Detailed Description' and 'Story Points' columns were performed. No rows were dropped (`Dropped 0 rows during data cleaning`), indicating the relevant columns in the 200 records were complete and properly formatted for the model.

### 3. Methodology

The following steps were taken to build and evaluate the predictive model:

* **Data Preparation:** The 'Detailed Description' and 'Story Points' columns were selected from the loaded dataset. Missing descriptions were filled with empty strings, and any non-numeric or missing Story Points were handled (though none were found in the 200 records).
* **Data Splitting:** The dataset was split into training and testing sets to evaluate the model on unseen data. An **80/20 split** was used, resulting in **160 samples for training** and **40 samples for testing**.
* **Text Vectorization:** Since machine learning models require numerical input, the 'Detailed Description' text was converted into numerical features using the **TF-IDF (Term Frequency-Inverse Document Frequency) vectorization** technique. The vectorizer was fitted on the training data and used to transform both training and testing descriptions. This process resulted in **37 numerical features** representing words/terms from the descriptions (`Training data shape after vectorization: (160, 37)`, `Testing data shape after vectorization: (40, 37)`).
* **Model Selection and Training:** A **Random Forest Regressor** model was chosen for the prediction task. This model is well-suited for regression and typically performs well with the types of features generated by TF-IDF. The model was trained on the vectorized training data and their corresponding Story Points.

### 4. Results

The trained model was evaluated on the test set (40 unseen issues) using standard regression metrics:

* **Mean Absolute Error (MAE): 0.1167**
    * Interpretation: On average, the model's predicted Story Points were off by only approximately 0.12 points from the actual Story Points in the test set.
* **Root Mean Squared Error (RMSE): 0.1799**
    * Interpretation: This metric, which gives more weight to larger errors, also showed a very low average error, on the same scale as Story Points.
* **R-squared (R2): 0.9943**
    * Interpretation: An R-squared value of 0.9943 indicates that the model explains approximately **99.43% of the variance** in the Story Points within the test set. This is an exceptionally high R-squared value for a real-world prediction task based on text.

**Evaluation Plots:**

Standard evaluation plots (Actual vs. Predicted, Residuals vs. Predicted, and Distribution of Residuals) were generated. Based on the high R-squared and low error metrics, these plots likely demonstrated:
* A strong linear relationship between actual and predicted Story Points, with points tightly clustered around the ideal diagonal line.
* Residuals (errors) that were small and appeared randomly scattered around zero when plotted against predicted values.
* A distribution of residuals centered very close to zero, indicating no significant systematic over- or under-prediction.

### 5. Model Explanation (SHAP)

To understand which words or features were most influential in the model's predictions, **SHAP (SHapley Additive exPlanations)** was used. SHAP values explain how each feature contributes to the prediction for an individual instance, pushing it higher or lower from the average prediction (base value).

* **SHAP Summary Plot:** A summary plot was generated for the full test set. This plot visually summarized the impact of the most important words (features) across all test issues. It would typically show which words consistently had a large positive impact (increasing predicted Story Points) and which had a large negative impact (decreasing predicted Story Points), as well as the spread of their impact.
* **Individual SHAP Decision Plots:** To gain deeper insight into specific predictions, SHAP decision plots were generated for 5 random issues from the test set. These plots showed the path from the average predicted Story Point value to the specific predicted value for that issue, illustrating how the presence and importance of certain words in the 'Detailed Description' cumulatively influenced the final prediction. For example, the plots showed the detailed contributions for issues with Original DataFrame Indices 125, 174, 84, 124, and 60, along with their actual and predicted Story Points (e.g., predicting 1.16 for Actual 1, 1.99 for Actual 2, 7.85 for Actual 8, 2.85 for Actual 3, 4.52 for Actual 5).

### 6. Making Predictions on New Data

Following the training and evaluation of the model, steps were taken to enable the prediction of Story Points for new, unseen Jira issue detailed descriptions and to understand the reasoning behind these individual predictions.

* **Saving the Trained Components:** The trained `RandomForestRegressor` model, the fitted `TfidfVectorizer`, and the initialized **SHAP Explainer** were saved to disk using the `joblib` library. These components were saved as `story_point_model.pkl`, `tfidf_vectorizer.pkl`, and `shap_explainer.pkl`, respectively. This was implemented by adding saving commands within the relevant notebook cells (Cell 2 for the model/vectorizer, Cell 4 for the explainer).
* **Loading for New Predictions:** Code was added to a subsequent cell in the notebook to load these saved `.pkl` files (`story_point_model.pkl`, `tfidf_vectorizer.pkl`, `shap_explainer.pkl`) into memory. This allows the trained model, the exact vectorization scheme, and the explainer to be quickly accessed for new predictions.
* **Prediction and Explanation Function:** A Python function (`predict_story_points_with_explanation`) was defined in the notebook. This function takes a new detailed description (as a string, supporting multi-line input) as input. It uses the loaded vectorizer to transform the text and then passes these features to the loaded model for a Story Point prediction. Crucially, this function also utilizes the loaded SHAP explainer to calculate SHAP values specifically for the input description.
* **Interactive Prediction and Explanation:** With the loading and enhanced prediction function in place, a separate cell was added to demonstrate its use. Users can provide a new detailed description (using multi-line strings). Upon execution, the cell calls the function, which not only returns the predicted Story Point value but also generates and displays a **SHAP explanation plot (e.g., a force plot)** for that specific prediction. This plot visually highlights which words in the new description had the biggest positive (increasing the prediction) or negative (decreasing the prediction) impact on the final Story Point estimate, relative to the average prediction on the training data.

This capability allows the notebook to transition from a purely analytical report to a practical tool that provides both predictions and explainability for new Jira issues, assisting users in understanding the factors influencing the estimated effort.

### 7. Conclusion

A machine learning model (Random Forest Regressor) was successfully trained to predict Jira issue Story Points using the detailed descriptions as input. The model demonstrated **exceptionally high performance** on the test set, with an R-squared of 0.9943 and a Mean Absolute Error of only 0.1167 Story Points. This indicates that, on this specific dataset, the 'Detailed Description' contains very strong predictive signals for 'Story Points'.

SHAP analysis provided valuable explainability, identifying the key words and phrases influencing predictions both overall (summary plot) and for individual issues (decision plots). This allows for a deeper understanding of the model's reasoning.

Furthermore, the model, vectorizer, and SHAP explainer were successfully saved, and a method was implemented within the notebook to load these components and facilitate the prediction of Story Points for new, user-provided detailed descriptions, **including generating a SHAP explanation for each individual prediction**. This transforms the analysis into a powerful tool for assisting with story point estimation by providing not just a prediction but also insights into *why* that prediction was made.

While these results are promising, it's important to consider that performance on a larger or different set of Jira issues might vary depending on the consistency of story point assignments and description quality in that data.
